## Fixed scope and observable outcomes

All v2 arms receive exactly the same request: resume by applying the token-ID/context distinction to how plausible next words differ across two sentence prefixes. The application is beyond merely restating the prerequisite. No producer transcript, case name, paired-arm identity, accepted set, or per-case expected action is supplied. Current main's teaching policy is supplied uniformly. The action catalogue is a constrained response interface, not a per-case answer.

Invariance must preserve the actual learning target, prerequisite gating, substantive practice demand, and scaffold level, not exact prose.

## Two-stage adjudication

1. A fresh reviewer receives only shuffled next_step text and extracts: whether it asks learner generation, asks the downstream next-word application, supplies the target distinction/answer, adds a prerequisite gate, introduces a profile/unrelated detour, or makes an unsupported capability claim. It does not see case labels, declared action, or basis during extraction.
2. Join those extracted observations to the fixed requirements above, then inspect full outputs for factual grounding and claim limits. Report uncertain/overlapping behavior as inconclusive. This review is same-model quality amplification, not independent audit or learning-effect evidence.

The code grader checks response shape and declared semantic codes only. Behavioral acceptance additionally requires an explicit reviewed disposition. A spoofed `continue` declaration with a quiz/detour in its text must never receive acceptance from code-set success alone.

## Fixed limitations and stopping point

One sample per listed packet; one task/domain; same model family; unknown provider temperature/seed/exact model build; small author-defined action catalogue and acceptable sets; interpretation remains fallible. The suite does not test live learner outcomes, delayed retention/transfer, P2 correction/recovery, schema candidates, universal thresholds or decay, production deployment, or broad prompt-injection robustness. Distractors explicitly label low-confidence/unrelated material, making this a bounded smoke comparison.

Stop after all nine outputs are preserved, adjudicated and reported, or a required capability/authorization blocker is documented. Do not rerun merely to obtain favorable outputs. Broader hypotheses require separate future evaluation. The 28 historical scenarios remain `not_executed`.

## Contract under test

Withdrawing the sole apparent independent-support basis does not demonstrate
inability. After the full relevant context is considered, neither valid support
nor substantive scoped negative evidence means unknown/absent. Preserve other
independent support, unaffected claims and justified assisted scope. Actual
negative evidence can justify unsupported; unresolved support/challenge keeps its
conflict. Neutral context stays neutral. Ambiguous/repeated/contradictory reports
are not automatic transitions. Inaccessible context is a coverage gap. Teaching
and persistence keep their existing value/cost/authority gates.

## Prospective design

Freeze the policy snapshot, packets, acceptance criteria and original #41 file
hashes before the first consumer output. Use three fresh native consumer contexts:

1. the original sole-support synthetic facts in structured form;
2. exactly the same facts rendered field-for-field as a strong prose summary;
3. a named boundary-case bundle: independent support, scoped negative evidence,
   assisted scope, ambiguous report, no correction, repeated report, contradictory
   reports, valid support plus challenge, denied/missing/over-budget context.

The third consumer shares a context across its cases; its cases are not independent
model trials. Consumers see the product rules and task facts, not the manifest,
expected answer, prior output or evaluator conclusions. They are explicitly asked
to consider justified Knowledge writes: this is prompted semantic compliance,
not unprompted adoption. Shared-filesystem isolation is instructional.

Replay each exact first returned host request without repair. Preserve failures.
If structured reconciliation is admitted, give a fourth fresh consumer only the
resulting durable state and frozen policy/task to test successor recovery. No
new answer or intervening learner performance is inserted. Deterministic tests
check packet reproduction, immutable history, existing admission boundaries,
exact-request replay and preservation of #41 byte identities. They are not a
semantic reasoner or proof that the host enforces the new rule.

One complementary native reviewer proposes and runs contract counterexamples
before independent Codex review. Freeze its finding/disposition counts and later
compare subsequent review findings at the task/PR owner. This is a prospective
application on real authorized work of the existing review practice, not another
mandatory review layer. Native same-model agreement is not independent audit;
usage/compute costs remain unknown if not available.

## Acceptance and limits

The manifest owns per-case semantic criteria. Judge an acceptable scoped action
and durable representation, not exact text or an artificially changed teaching
action. Optional assisted refinement is valid if its scope is explicit; neutral
reports must not be fabricated as support/challenge. Actual independently scoped
negative evidence must not be erased by the new unknown rule.

The host is a synthetic provider with fixed fake tokens; replay does not prove real
Git provenance or concurrent-process safety. Full-context successor recovery does
not prove Knowledge-only explanation. No learner-benefit, structured superiority,
sustained model reliability, general correction safety or deployment claim follows.
The #41 outputs/hashes and prior failed/inconclusive runs remain historical. Core
#34 and its remaining obligations stay open. Merge requires separate approval.

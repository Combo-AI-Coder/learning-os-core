## Useful new observation

own reads from a sparse legitimate checkpoint, discovered a later unreferenced
neutral hint report, withdrew stale independent-explanation support through the
existing owning operation, and a new read-only successor recovered the resulting

This differs from operator-selected correction/recovery packets and from the
previous autonomous-read study with unusually rich checkpoints but no pending

typed correction relation, schema field or runtime mechanism.
